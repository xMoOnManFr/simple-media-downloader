Simple media downloader use the yt-dlp and ffmpeg package

(to note that the python script contains a GUI and the released exe doesn't )

MAKE SURE THAT YOU INSTALLED YT-DLP AND FFMPEG OTHERWISE IT WONT WORK AT ALL

On windows : winget install yt-dlp.yt-dlp | winget install ffmpeg

NOT made for linux and macos and probably will never try to make it work
